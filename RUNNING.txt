MiniVectorDB：可查询日志 C++ 引擎

分支 minivectordb-rewrite。默认入口 /app/minivectordb-log，默认数据目录 /data。
原始 float32 向量用于最终精算；exact/ann 当前均返回精确结果。
协议保持 JSONL：启动输出 {"type":"ready"}，每次响应立即刷新，诊断写 stderr。
完整提交目录帧写入 queryable.log 并 fsync 成功后才确认提交。
EOF/shutdown 回滚未提交事务。checkpoint 同步新日志、原子替换并同步目录。

构建
固定 GCC 12 / Python slim 基础镜像摘要，依赖源码与哈希随仓库交付。
RUN 不执行 apt/pip 或联网下载；首次使用前需缓存 Dockerfile 指定的基础镜像。
docker build --platform=linux/amd64 --no-cache --network=none -t minivectordb:queryable .

运行（使用空数据卷）
docker volume create minivectordb-queryable-data
docker run --rm -i --network=none --cpus=1 --memory=2g --memory-swap=2g --pids-limit=128 --read-only --cap-drop=ALL --security-opt=no-new-privileges --mount type=volume,src=minivectordb-queryable-data,dst=/data minivectordb:queryable
也可设置 2 CPU；实际测评的内存限额可能更小，已补测 16/64 MiB。

当前默认组合
整数辅助筛选与紧凑解析开启；MINIDB_POSTINGS=0 关闭候选列表，使用已验证位图路径。
列表在本次三对实验中没有稳定收益，因此不默认启用。保留代码供显式开关复核。
MINIDB_QUANT_SCREEN=0、MINIDB_COMPACT_VECTOR=0 分别禁用整数筛选、紧凑解析；
MINIDB_INDEX_MMAP=0 禁用映射，MINIDB_SIMD=0 禁用 SIMD，MINIDB_FLOAT_SCREEN=0 禁用浮点筛选。
MINIDB_DIAGNOSTICS=1 输出实际路径计数。优化不适用、预算不足时回退到原始向量精算。
